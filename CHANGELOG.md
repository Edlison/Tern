# Changelog

## 0.7.0 — Tern release candidate

- Rename the native app and Swift package to Tern; introduce original folded-wing artwork.
- Align provider indicators with verified brand sources: official Codex icon sample blue, Anthropic clay, neutral Grok white.
- Replace the static central cross with a slow, irregular idle dot field; preserve provider-colored running streams and Reduce Motion.
- Restrict configurable widths to 120–240 pt idle and 240–360 pt active, independent of live text/counts.
- Retain Current/History navigation, direct session opening, hover-only expansion and persisted per-delivery review confirmation.
- Add source audit, macOS CI, universal preview packaging, explicit Developer ID/notarization gates and public release documentation.
- Preserve existing settings/inbox through the legacy application identifier.

Monitoring adapters remain version-sensitive; see the integration notes. The local preview is not notarized.
