# Tern

一个安静的原生 Mac Agent 状态栏。让 Agent 继续工作，结果回来时能看见。

## 使用

打开 `build/Tern.app`。关闭任务中心后，刘海和菜单栏仍会监听；从菜单退出才停止。仅悬停会展开，交付不会自动展开或抢焦点。

工作区只有两个部分：

- **当前会话**：执行中，以及还有待检查结果的 session。
- **历史会话**：其余会话。点击任意一行，直接回到原 Agent。

绿色提示只代表未确认结果。查看信号按 session 和本轮交付匹配；启动某个 Agent App 不会清除它的所有会话。新一轮结果需要重新查看。

## 自定义

“状态栏布局”可拖动组件、排序、移除，分别保存两种状态：静态 **120–240pt**，运行 **240–360pt**。长文字省略，数量变化不会拉长外框。有物理刘海的屏幕还会额外预留摄像头和两侧空间。

空闲点阵缓慢、不规则地明暗流动；运行时改为对应 Agent 的颜色，多种 Agent 同时运行时出现多色。减少动态效果开启后使用静止图案。

“外观与刘海”用色卡选择整体主题。Agent 标识颜色独立于主题：Codex 官方应用图标取样蓝、Claude 官方陶土橙、Grok 中性白。配色依据见 [BRAND.md](BRAND.md)。

## 声音与 HomePod

先在 macOS 控制中心连接 HomePod / AirPlay 输出，再在 Tern 的“声音与 HomePod”中选择系统默认输出或已有的 CoreAudio 输出。支持自定义音频、音量、系统本地语音和播报模板：`{agent}`、`{title}`、`{status}`、`{summary}`。

静音时保留待检查提示。系统通知需在应用中单独开启，并受系统通知权限和专注模式影响。HomePod 是否可用取决于 macOS 是否暴露该输出；没有自建私有配对协议。

## 数据与限制

读取本地 Agent 日志，以及已有连接的 SSH 主机日志；Codex 云端使用已登录 CLI。不会提交新 Agent 指令，不修改源 App 的已读状态。纯 SSH session 的点击入口只恢复原 session，不附带新提示词。

Claude 云端、Grok 的缓存可能延迟或停更；没有可靠回执的会话仍会保留提示。“本轮完成”不保证代码正确，“收到回复”不等于整个长期任务结束。睡眠期间不监听。完整边界见 [INTEGRATIONS.md](INTEGRATIONS.md)。

从源码构建：`swift test`，然后 `./scripts/build.sh`。公开分发前需使用 [RELEASING.md](RELEASING.md) 中的签名公证流程。本地预览包不等于已公证发行版。
